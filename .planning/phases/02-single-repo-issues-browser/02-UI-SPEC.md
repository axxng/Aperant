## Spacing Scale

Declared values (multiples of 4 only). Use Tailwind utility classes — no magic numbers.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`) | Label dot gaps, icon-to-text gaps in list rows |
| sm | 8px (`gap-2`, `p-2`) | Between list-row metadata items, filter bar internal padding |
| md | 16px (`gap-4`, `px-4`) | Filter bar horizontal padding, detail panel section spacing |
| lg | 24px (`gap-6`, `p-6`) | Detail panel internal padding, empty state content padding |
| xl | 32px (`gap-8`) | Not used in this phase |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Issue list row height: `h-11` (44px) — minimum touch target for clickable rows
- Assignee avatar: `h-5 w-5` (20×20px) — matches TaskCard existing pattern
- Label color dot: `h-2 w-2` (8×8px) — matches TaskCard existing pattern
- Detail panel width: `w-[40%]` on desktop, `w-full` on mobile

Source: CONTEXT.md D-04, D-05, D-06; TaskCard.tsx existing patterns

## Layout Contract

### Overall Layout
```
┌─────────────────────────────────────────────────────────┐
│  Product content area                                    │
│  ┌─────────────────────────────────────────────────┐    │
│  │  Tab switcher: [Kanban] [Issues]  (underline)   │    │
│  └─────────────────────────────────────────────────┘    │
│  ┌─────────────────────────────────────────────────┐    │
│  │  IssuesFilterBar (search + label + assignee +   │    │
│  │  state toggle + reset)                          │    │
│  └─────────────────────────────────────────────────┘    │
│  ┌───────────────────────┬─────────────────────────┐    │
│  │  Issues list (60%)    │  Detail panel (40%)     │    │
│  │  - IssueListRow × N   │  slide-in, overflow-y   │    │
│  │  - "Load More" btn    │  auto via ScrollArea    │    │
│  └───────────────────────┴─────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

- Tab switcher: `flex border-b border-border` with `NavLink` pairs; active tab has `border-b-2 border-primary text-foreground`, inactive has `text-muted-foreground hover:text-foreground`
- Filter bar: `flex items-center gap-2 px-4 py-2 border-b border-border` — mirrors `KanbanFilterBar` exactly
- Split pane: `flex flex-1 overflow-hidden` — list pane `flex-1 overflow-y-auto`, detail panel `w-[40%] border-l border-border overflow-y-auto` (hidden when no issue selected)
- On mobile (`< 768px`): detail panel covers full width, overlaid above the list

### IssueListRow anatomy
```
h-11 flex items-center gap-3 px-4 border-b border-border hover:bg-accent/50 cursor-pointer
├── #NNN (text-[11px] text-muted-foreground w-12 shrink-0)
├── title (text-sm font-normal flex-1 truncate)
├── label dots (flex gap-1 — h-2 w-2 rounded-full, max 4 visible)
├── assignee avatar (h-5 w-5 rounded-full)
└── state badge (Badge variant="success"|"muted" text-[10px])
```

### Detail Panel anatomy
```
flex flex-col p-6 gap-4
├── header: issue title (text-base font-semibold) + #NNN + state badge
├── meta row: labels (full Badge with color bg) + assignee (avatar + login) + created date
├── "View on GitHub" link (Button variant="link" size="sm", ExternalLink icon)
├── divider
└── Markdown body (react-markdown + remark-gfm, prose-sm styling)
```

## Interaction Contract

### Tab Switcher
- `NavLink` with `end` prop for Kanban (`/products/:productId`), without `end` for Issues (`/products/:productId/issues`)
- Active state: `border-b-2 border-primary font-medium`
- Transition: none (instant)

### Filter Bar
- Search: `onChange` → client-side filter, no debounce needed (client-side only per D-10)
- Label dropdown: `DropdownMenuCheckboxItem` multi-select; active filter count shown as `Badge variant="muted"` on the trigger button
- Assignee dropdown: `DropdownMenuRadioItem` single-select; "All assignees" as default radio item
- State toggle: two `Button variant="ghost" size="sm"` items: "Open" and "Closed"; active state uses `bg-accent text-accent-foreground`
- Reset button (X icon): appears only when `hasActiveFilters === true`; uses `Button variant="ghost" size="sm"`
- Filter changes: reset page to 1, replace list (D-13)

### Issue List
- Row click: sets selected issue ID in component state; replaces detail panel content without closing panel
- Selected row: `bg-accent/50 border-l-2 border-primary`
- Hover: `hover:bg-accent/50` (same as selected minus the left border)
- "Load More" button: `Button variant="outline"` centered below list; hidden when `hasMore === false`; shows `Loader2 animate-spin` icon while loading next page

### Detail Panel
- Appears: CSS `translate-x-0` when issue selected; hidden via `translate-x-full` when no selection (transition: `transition-transform duration-250 ease-out`)
- Close: no explicit close button; clicking another row replaces content; URL-driven (no issue param = panel hidden)
- Markdown: `react-markdown` with `remark-gfm`; no `dangerouslySetInnerHTML`; apply `prose prose-sm dark:prose-invert max-w-none` Tailwind typography classes (install `@tailwindcss/typography` if not present)

### Loading State
- 8 `IssueSkeletonRow` components rendered while first fetch is in-flight
- Skeleton rows: same `h-11` height as real rows; use `animate-pulse bg-muted rounded`
- "Load More" fetch: spinner in the button, list rows remain visible

### Empty State
- Centered in the list pane: GitHub `GitBranch` icon (lucide, `h-8 w-8 text-muted-foreground`), heading, body text, external link button
- Displayed when: fetch resolves with 0 issues for the current state filter

### Error State
- Replaces list content with: `AlertCircle` icon, heading, body copy, retry button (`Button variant="outline" size="sm"`)
- Labels fetch failure: does not block issues load; shows inline error inside the label dropdown ("Could not load labels. Filters may be incomplete.")
