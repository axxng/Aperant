## Deviations

1. **define block removed** — `vite.config.ts` define block read `process.env.MOCK_SERVICES` at config evaluation time (before Vite loads `.env.local`), always resolving to `'false'`. Removed; Vite's built-in `VITE_*` env handling is sufficient.

2. **DevModeBanner moved to login page** — original placement was inside `AuthenticatedApp` only; banner was invisible to unauthenticated users. Moved to render on both login and authenticated views.

3. **Mock issues response shape fixed** — mock route returned raw `IssueFixture[]` array; `AllIssuesView` expects `PaginatedIssuesResult` (`{ issues, hasMore }`) with camelCase fields. Fixed to transform and wrap correctly.

4. **Unique issue IDs per repo** — all repos shared IDs 10001–10020 causing duplicate React keys in `AllIssuesView`. Fixed with a hash-based per-repo ID offset.
