## Parse-Don't-Validate Scope

| Option | Description | Selected |
|--------|-------------|----------|
| API boundary only | Trust the DB — rows from own writes, blind casting is acceptable; Zod only at external input | |
| DB rows too | Add Zod to rowToTask() and similar DB-row-to-domain mappers | |
| All untrusted data | Zod at API input, DB rows, AND raw GitHub API responses (mapGitHubIssue/mapGitHubPR) | ✓ |

**User's choice:** All untrusted data — parse at every system boundary

---

### Parse failure handling

| Option | Description | Selected |
|--------|-------------|----------|
| Throw, let handler catch | z.parse() throws ZodError; handler's try/catch returns 500 | ✓ |
| Return null / undefined | z.safeParse() returns null; callers must handle null at each callsite | |
| Return typed Result<T, ParseError> | Explicit error propagation but adds boilerplate | |

**User's choice:** Throw — parse errors are programmer/deployment bugs, not user errors

## FSM / Illegal State Scope

### Which domains get FSM treatment

| Option | Description | Selected |
|--------|-------------|----------|
| Task status transitions | VALID_TRANSITIONS map or discriminated union per state | ✓ |
| OAuth callback state | Explicit state machine: NoCode → CodeReceived → TokenExchanged → UserFetched → Complete | ✓ |
| GitHub sync state | Replace githubSyncPending bool + retryCount int with discriminated union | ✓ |
| Triage state | TriageUntouched | TriagePrioritized | TriageComplete discriminated union | ✓ |

**User's choice:** All four domains

---

### Task status FSM strictness

| Option | Description | Selected |
|--------|-------------|----------|
| Runtime guard + typed transition fn | transitionTaskStatus(from, to) validates against VALID_TRANSITIONS map | |
| TypeScript type-level enforcement | Template literal types / conditional types; compiler rejects invalid pairs | |
| Discriminated union per state | Every TaskStatus variant carries only its valid fields | ✓ |

**User's choice:** Full discriminated union per state — every variant typed to only carry valid fields

**Notes:** High surface area — cascades to frontend Task type consumers (KanbanBoard, TaskCard, TaskEditDialog, task-store). DB flat structure unchanged; rowToTask() assembles the correct union variant based on status column value.
