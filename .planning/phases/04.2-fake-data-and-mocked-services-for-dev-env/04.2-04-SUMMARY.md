## What Was Built

`apps/web/scripts/seed.ts` is a deterministic CLI seeder for the local dev SQLite database. It:

- Guards against real Turso DB writes by checking `MOCK_SERVICES === 'true'` at the top of the file (before any imports that could open a DB connection), calling `process.exit(1)` if not set
- Loads `.env.local` via `dotenv` before the guard check
- Calls `faker.seed(12345)` once at module level so every run produces identical data
- Is idempotent: clears `issue_triage`, `tasks`, `task_order`, `products`, and `users` with `executeMultiple` before inserting
- Creates exactly 1 admin user (`dev-admin@github.invalid`, `role=admin`, `github_login=dev-admin`)
- Creates exactly 3 products with colors `#3B82F6`, `#10B981`, `#F59E0B` and sources JSON pointing to mock-org repos
- Creates 8 tasks per product — one per Kanban status (`backlog`, `queue`, `in_progress`, `ai_review`, `human_review`, `done`, `pr_created`, `error`)
- `pr_created` tasks include `github_issue_number`, `github_issue_url`, and `github_repo` (required fields)
- `ai_review`, `human_review`, `error` tasks include `review_reason = 'Needs review'`
- Creates 3 `issue_triage` records per product (1 triaged with `priority=high`, 2 untriaged)
