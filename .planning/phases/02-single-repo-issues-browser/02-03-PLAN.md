## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Information Disclosure | QueryClient cache | accept | Cache holds GitHub issue data (public repos) or repo data the user is already authenticated to view; no new exposure beyond what the user can already see |
| T-02-03-02 | Tampering | i18n interpolation `{{retryAfter}}` | accept | `retryAfter` is a server-returned number (seconds); react-i18next interpolates into string safely without HTML injection |
| T-02-03-03 | Repudiation | IssuesView route added to App.tsx | accept | Route addition is additive; no existing routes removed or permissions changed |
</threat_model>
