| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04-01 | Spoofing | /issues route — unauthenticated access | mitigate | `App.tsx` renders `<LoginPage />` when `!token || !user` — unauthenticated users never see `AuthenticatedApp` containing the `/issues` route [VERIFIED: App.tsx lines 60-64] |
| T-04-04-02 | Information Disclosure | /issues renders issues from all products | accept | User is authenticated (T-04-04-01); each product's issues fetched with user's own OAuth token via `credentials: 'include'`; server validates per-user token access [VERIFIED: issues.ts authenticateRequest] |
| T-04-04-03 | Elevation of Privilege | AllIssuesView shows issues from all products regardless of per-product access | accept | Current data model has no per-product access control — all authenticated users see all products. This is a Phase 4 scope boundary; role-based product access is out of scope for this milestone |
